# Security policy

## Supported versions

The latest tagged release receives security fixes.

## Reporting

Please open a private GitHub Security Advisory for vulnerabilities in Surfaceproof. Do not file a public issue containing active credentials, private target evidence, personal data, or undisclosed third-party findings.

Include a synthetic reproducer, affected version, expected/actual behavior, and mitigation ideas where possible. Luke Schneider will acknowledge a complete report as soon as practical and coordinate remediation and disclosure.

## Tool boundaries

Surfaceproof does not authorize testing any system. Operators are responsible for permission, scope, safe harbor, rate limits, data handling, and disclosure requirements.
